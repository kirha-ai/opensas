# STAT-VARCOMP-001 — VARCOMP — Data input, variable roles, and basic options

## Source

S154 / Chapter 130 / `PROC VARCOMP Statement` (PDF pp. 10730–10731); S154 / Chapter 130 / `BY Statement` (PDF p. 10731); S154 / Chapter 130 / `Missing Values` (PDF p. 10733).

## Scope

Integrate PROC VARCOMP declarations, basic options, defaults, and execution boundaries; this ticket establishes parameter objects and result interfaces, while later feature tickets implement model-, algorithm-, and output-specific options. Also implement BY; Missing Values; apply this procedure's rules for missing values, variable roles, and observation selection.

## Acceptance criteria

Create positive and negative parsing cases for the documented declarations and basic options; verify defaults, explicit settings, documented duplicate/conflicting declarations, and locations; valid but unimplemented features must not silently succeed. For BY / Missing Values, construct valid, missing, empty, and multiple-group inputs; verify included observation counts, variable roles, BY boundaries, level ordering, and the frequency/weight rules relevant to this ticket; assert documented invalid-input behavior.
